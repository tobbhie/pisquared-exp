# Pi2 Explainer Chrome Extension

Chrome extension that provides AI-powered explanations for PiSquared content.

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select this `chrome-extension` directory
5. Configure backend URL in extension popup

## Features

- Text selection detection
- Floating "Explain" button
- Explanation overlay with sources
- Feedback system
- Keyboard shortcut (Alt+E)

## Usage

1. Visit https://pi2.network
2. Select text (minimum 10 characters)
3. Click "💡 Explain" button
4. View explanation in overlay

## Configuration

Click the extension icon to configure:
- Backend API URL (default: http://localhost:3001)
